## 7. 设计规格（可直接落地）

### 7.1 颜色

```
--bg:#000; --surface:#141414; --line:rgba(255,255,255,.11);
--fg:#fafafa; --muted:rgba(255,255,255,.64); --faint:rgba(255,255,255,.45);
--accent:#10b981;  /* 只给数据 */
```

### 7.2 字体

- 标题：`Poppins` 500/600，`-0.02em`，行高 1.05–1.1；中文回退 `"PingFang SC","HarmonyOS Sans SC",MiSans,"Microsoft YaHei"`。
- 正文：`Inter` 400/500，16/14，行高 1.65。
- 微标签：`Geist Mono` 10–12，大写，`letter-spacing:.1em`。
- 中文标题**不要**用负字距（CJK 会挤）；只在拉丁段落用。

### 7.3 字号阶梯

48 / 36 / 30 / 22 / 18 / 16 / 14 / 12 / 10（9 档，与参照站一致；落地时保留 8 档以内）。

### 7.4 动效

- 进场：`opacity 0→1 + translateY 8px`，500ms，`cubic-bezier(.2,.6,.2,1)`，只播一次。
- 拼贴拖拽：1:1 跟手，边界 ±150px，无惯性。
- 切语言：不重排动画，仅文本替换。
- `prefers-reduced-motion: reduce` → 全部关闭（含拖拽的过渡，但拖拽本身保留）。

### 7.5 页面结构（8 块，功能不变）

1. **Nav**：黑底渐隐；滚动后 `backdrop-blur` + 发丝线；左 logo+字标；中 4 锚点；右 Star / 中EN / 下载小按钮。
2. **Hero**：`min-h-svh`；照片拼贴（可拖）+ 主窗口卡；底部左标题、右副文+双 CTA；底部渐变压黑。
3. **演示**：整宽 hairline 窗 + mono 说明；嵌入现有 `ImageFilterDemo`。
4. **对比**：两列 hairline 卡片，emerald 勾；去掉 VS 大圆与发光。
5. **特性**：3×2 卡片，mono 编号 01–06，图标 20px 灰。
6. **工作流**：3 步，mono 大编号 + 细线。
7. **下载**：版本徽章仍从 GitHub `/releases/latest` 取；推荐卡白底按钮；国内直链一行；MSI 说明保留。
8. **Footer**：品牌+tagline、3 列链接、细分隔线、mono 版权。

## 9. 技术要点与坑

- `@/` alias 指向 **`src/demo/ui`**（落地页复用了 demo 里的动效组件）。新写的落地页组件请放 `src/landing/`，别放 `demo/ui`，否则会被主仓库同步覆盖。
- 现有落地页的紫蓝流体 = `LiquidEther` / `ParticleText` / `ClickSpark` / `BorderGlow` / `SpecularButton`。改版只需**停止引用**，不要删文件（它们在 `demo/ui` 副本里）。
- `src/main.tsx` 为 `LiquidEther` 的 WebGL 双挂载禁用了 StrictMode；移除流体后是否恢复 StrictMode，需单独验证 demo 是否受影响。
- `src/demo/app-version.ts` 是演示里显示的软件版本，必须跟主仓库 `package.json` 一致（当前 **1.1.2**，主仓库 **1.3.0**）。
- `vite base: "/"` → `xutengxiang.github.io/ImageFilter-Website/` 取不到资源；线上真正可用的是 `tensyn.online/imagefilter/`。
- 下载区版本号与三条直链是运行时从 GitHub 取的，**发新版不用改页面**；只有 `CN_DOWNLOADS`（蓝奏云）是手动的。
- 中文字体走系统栈，Windows 上会落到微软雅黑；标题字重 600 在雅黑上偏重，必要时降到 500 并加 `letter-spacing:0`。
