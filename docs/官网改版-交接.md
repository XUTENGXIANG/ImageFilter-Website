## 7. 设计规格（可直接落地）

### 7.1 颜色

```
--bg:#000; --surface:#141414; --line:rgba(255,255,255,.11);
--fg:#fafafa; --muted:rgba(255,255,255,.64); --faint:rgba(255,255,255,.45);
--accent:#10b981;  /* 只给数据 */
```

### 7.2 字体

- 标题：`Poppins` 500/600，`-0.02em`，行高 1.05–1.1；中文回退 `"PingFang SC","HarmonyOS Sans SC",MiSans,"Microsoft YaHei"`。
- 正文：`Inter` 400/500，16/14，行高 1.65。
- 微标签：`Geist Mono` 10–12，大写，`letter-spacing:.1em`。
- 中文标题**不要**用负字距（CJK 会挤）；只在拉丁段落用。

### 7.3 字号阶梯

48 / 36 / 30 / 22 / 18 / 16 / 14 / 12 / 10（9 档，与参照站一致；落地时保留 8 档以内）。

### 7.4 动效

- 进场：`opacity 0→1 + translateY 8px`，500ms，`cubic-bezier(.2,.6,.2,1)`，只播一次。
- 拼贴拖拽：1:1 跟手，边界 ±150px，无惯性。
- 切语言：不重排动画，仅文本替换。
- `prefers-reduced-motion: reduce` → 全部关闭（含拖拽的过渡，但拖拽本身保留）。

### 7.5 页面结构（8 块，功能不变）

1. **Nav**：黑底渐隐；滚动后 `backdrop-blur` + 发丝线；左 logo+字标；中 4 锚点；右 Star / 中EN / 下载小按钮。
2. **Hero**：`min-h-svh`；照片拼贴（可拖）+ 主窗口卡；底部左标题、右副文+双 CTA；底部渐变压黑。
3. **演示**：整宽 hairline 窗 + mono 说明；嵌入现有 `ImageFilterDemo`。
4. **对比**：两列 hairline 卡片，emerald 勾；去掉 VS 大圆与发光。
5. **特性**：3×2 卡片，mono 编号 01–06，图标 20px 灰。
6. **工作流**：3 步，mono 大编号 + 细线。
7. **下载**：版本徽章仍从 GitHub `/releases/latest` 取；推荐卡白底按钮；国内直链一行；MSI 说明保留。

## 9. 技术要点与坑

- `@/` alias 指向 **`src/demo/ui`**（落地页复用了 demo 里的动效组件）。新写的落地页组件请放 `src/landing/`，别放 `demo/ui`，否则会被主仓库同步覆盖。
- 现有落地页的紫蓝流体 = `LiquidEther` / `ParticleText` / `ClickSpark` / `BorderGlow` / `SpecularButton`。改版只需**停止引用**，不要删文件（它们在 `demo/ui` 副本里）。
- `src/main.tsx` 为 `LiquidEther` 的 WebGL 双挂载禁用了 StrictMode；移除流体后是否恢复 StrictMode，需单独验证 demo 是否受影响。
- `src/demo/app-version.ts` 是演示里显示的软件版本，必须跟主仓库 `package.json` 一致（当前 **1.1.2**，主仓库 **1.3.0**）。
- `vite base: "/"` → `xutengxiang.github.io/ImageFilter-Website/` 取不到资源；线上真正可用的是 `tensyn.online/imagefilter/`。
- 下载区版本号与三条直链是运行时从 GitHub 取的，**发新版不用改页面**；国内加速只是给 URL 加前缀，同样自动跟随最新版。
- 中文字体走系统栈，Windows 上会落到微软雅黑；标题字重 600 在雅黑上偏重，必要时降到 500 并加 `letter-spacing:0`。
- **demo 同步第 6 项（README 未写）**：1.3.0 组件使用 `text-brand` / `bg-brand-strong` / `text-danger` 等语义色类；`src/demo/index.css` 必须补 `--brand*` / `--danger*` / `--warning` / `--info` 变量与 `@theme inline` 映射，否则类静默不生成、按钮/状态失色。
- **`@tauri-apps/api/event`**：1.3.0 配对事件走动态 import；mock 要导出 `listen`，`tauri-types.d.ts` 要补 `declare module`，否则 `tsc -b` 直接失败。
- **首屏移动端导航**：原型在 `<900px` 隐藏锚点；正式实现保留 4 个锚点，第二行必须加 `bg-black/60 backdrop-blur`，否则链接压在照片上不可读。
- **移动端 demo**：软件 UI 是桌面布局，390 下会被裁切；`src/landing/DemoWindow.tsx` 给 `ImageFilterDemo` 加 `max-hero:min-w-[720px]` + 外层 `overflow-x-auto`，让用户横向滑动查看，页面本身仍无横向溢出。
- **英文标题空格**：`title.line2` 与 `title.emphasis` 分开渲染时，英文要在中间补空格（中文不补），否则会显示 `Keep onlythe keepers`。
- **demo 树行样式**：`src/demo/index.css` 必须带 `.tree-row { height:28px }`、`.tree-kids`、`.tree-caret`、`.press-row`。漏掉时文件夹树展开后各子树会压在一起（官网副本曾漏这一段）。
- **demo 浅色主题**：App 根容器透明，`:root[data-theme="light"] .ifdemo-scope` 要给浅色底；否则浅色主题中间露出落地页黑底。
- **demo 弹层约束**：`.ifdemo-scope .fixed { position:absolute !important }`，图片查看器/对话框/toast 才会留在 demo 框内，不铺满整页。
- **demo 设置入口**：官网演示隐藏 titlebar 齿轮（`button:has(.i-icon-setting)`），设置面板不开放；主仓库真机不受影响。
- **rewampui CLI**：本仓库 `components.json` 只有 react-bits 的 `registries`，没有顶层 `registryUrl`，直接 `npx rewampui add neumorphic-download-button` 会报 `Cannot read properties of undefined (reading 'replace')`；需要时从 `raw.githubusercontent.com/palakonweb/Rewamp-UI/main/registry/...` 取同一份源码，落 `src/landing/components/`，不要让它写进 `src/demo/ui/`。
- **FlapLabel 指针穿透**：按钮标签在 hover 时会重挂载；`.flap-button-label { pointer-events:none }` 必须保留，否则快速点击会落在被替换的 tile 上导致点击丢失。
- **公共加速前缀**：`ghfast.top` 是第三方服务，可能失效/限速/改写内容；只作为「国内加速」可选项，默认仍走 GitHub，并在 UI 显示风险提示。换服务只改 `src/landing/lib/downloadMirror.ts` 的 `MIRROR_PREFIX`；长期建议自建 Worker 反代。
